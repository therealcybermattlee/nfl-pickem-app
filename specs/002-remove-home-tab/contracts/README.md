# API Contracts: Remove Home Tab

**Feature**: 002-remove-home-tab
**Date**: 2025-11-22

## Overview

This feature requires **no API changes**. All existing endpoints remain unchanged.

## Existing Endpoints Used

### GET /api/games
Returns games for a given week and season. No changes needed.

```
GET /api/games?week=1&season=2025

Response: {
  games: Game[]
}
```

### GET /api/picks
Returns all picks. Already returns all family members' picks. No changes needed.

```
GET /api/picks

Response: {
  picks: [
    {
      id: string,
      gameId: string,
      userId: string,
      teamId: string,
      userName: string,
      teamAbbr: string,
      isLocked: boolean,
      autoGenerated: boolean,
      timeUntilLock: number | null
    }
  ]
}
```

### POST /api/picks
Submit a pick. No changes needed.

```
POST /api/picks
Body: { userId: string, gameId: string, teamId: string }

Response: {
  id: string,
  userId: string,
  gameId: string,
  teamId: string,
  isLocked: boolean,
  autoGenerated: boolean,
  timeUntilLock: number | null
}
```

## Why No New Endpoints

1. **GET /api/picks already returns all users' picks** - no need for a separate "family picks" endpoint
2. **Pick visibility logic is client-side** - based on game lock status
3. **User data is embedded in picks response** - `userName` field already present
4. **No new data aggregation needed** - client can filter/group picks by game

## Contract Stability

All existing API contracts remain stable. Frontend changes are isolated to:
- Routing configuration
- Navigation components
- GameCard component enhancement
- GamesPage state management
