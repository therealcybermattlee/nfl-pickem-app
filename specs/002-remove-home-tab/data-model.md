# Data Model: Remove Home Tab

**Feature**: 002-remove-home-tab
**Date**: 2025-11-22
**Status**: Complete

## Overview

This feature requires **no database schema changes**. It is a frontend-only refactor that removes the Home tab and consolidates UI functionality into the Games page.

## Existing Entities (No Changes)

### Picks Table
The existing picks table already contains all data needed for family picks display:

| Field | Type | Description |
|-------|------|-------------|
| id | TEXT | Primary key (UUID) |
| userId | TEXT | Foreign key to users |
| gameId | TEXT | Foreign key to games |
| teamId | TEXT | Foreign key to teams |
| createdAt | TEXT | Timestamp |
| updatedAt | TEXT | Timestamp |
| isLocked | INTEGER | Whether pick is locked (0/1) |
| autoGenerated | INTEGER | Whether pick was auto-generated (0/1) |

### Games Table
No changes needed. Existing fields support all requirements:
- `isLocked` - Used for pick spoiler prevention (FR-007)
- `status` - Used to determine game state
- `gameTime` - Used for lock timing

### Users Table
No changes needed. Existing user data supports family picks display.

## Data Flow

### Current Flow (No Changes to API)

```
GamesPage loads
    ↓
GET /api/games?week=X&season=Y → games[]
    ↓
GET /api/picks → allPicks[] (includes all users)
    ↓
Group picks by gameId → picksMap<gameId, Pick[]>
    ↓
For each game, filter picks → familyPicks[]
    ↓
Render GameCard with familyPicks prop
```

### Pick Visibility Logic

```typescript
function getFamilyPicksForGame(
  game: GameStatus,
  allPicks: Pick[],
  currentUserId: string
): FamilyPick[] {
  const gamePicks = allPicks.filter(p => p.gameId === game.id);

  return gamePicks
    .filter(pick => {
      // Always show current user's own pick
      if (pick.userId === currentUserId) return true;
      // Only show others' picks for locked games
      return game.isLocked || game.status === 'in_progress' || game.status === 'completed';
    })
    .map(pick => ({
      userId: pick.userId,
      userName: pick.userName,
      userInitial: USER_INITIALS[pick.userId] || pick.userName[0],
      userColor: USER_COLORS[pick.userId] || '#6B7280',
      teamId: pick.teamId,
      teamAbbr: pick.teamAbbr,
      isCurrentUser: pick.userId === currentUserId,
    }));
}
```

## State Transitions

No state machine changes. Game lock states remain unchanged:

```
upcoming → locked → in_progress → completed
           ↑
    (pick submission allowed until here)
```

## Validation Rules

### Pick Display Validation
- Only show family picks when `game.isLocked === true` OR game is in progress/completed
- Always show current user's own pick regardless of lock state
- Handle missing pick gracefully (user may not have picked yet)
