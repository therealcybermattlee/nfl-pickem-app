# NFL Pick'em App - API Documentation

## Base URL

**Production:** `https://nfl-pickem-app-production.m-de6.workers.dev`

## Authentication

All authenticated endpoints require a JWT token in the Authorization header:

```
Authorization: Bearer <token>
```

Tokens are obtained from the authentication endpoints and expire after 24 hours.

---

## Authentication Endpoints

### POST /api/auth/register

Register a new user account.

**Request Body:**
```json
{
  "email": "user@example.com",
  "password": "password123",
  "name": "John Doe"
}
```

**Validation:**
- Email: Valid email format required
- Password: Minimum 8 characters
- Name: 1-100 characters, letters/spaces/hyphens/apostrophes only

**Response (200 OK):**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "email": "user@example.com",
    "name": "John Doe",
    "role": "user"
  }
}
```

**Error Responses:**
- `400` - Validation error (password too short, invalid email, etc.)
- `409` - Email already exists

---

Get games for a specific week and season.

**Query Parameters:**
- `week` (optional, default: 1) - NFL week number (1-18)
- `season` (optional, default: 2025) - NFL season year

## Picks Endpoints

### POST /api/picks

Submit a pick for a game. **Requires authentication.**

**Headers:**
```
Authorization: Bearer <token>
```

**Request Body:**
```json
{
  "gameId": "1",
  "teamId": "1",
  "userId": "1"
}
```

**Response (200 OK):**
```json
{
  "id": 123,
  "gameId": "1",
  "teamId": "1",
  "userId": "1",
  "autoGenerated": false,
  "createdAt": "2025-09-04T18:30:00.000Z"
}
```

**Error Responses:**
- `400` - Game is locked (past deadline)
- `401` - Authentication required
- `404` - Game or team not found

---

### GET /api/picks/live-status

Get user's picks with live game status. **Requires authentication.**

**Headers:**
```
Authorization: Bearer <token>
```

**Query Parameters:**
- `userId` (required) - User ID
- `week` (required) - Week number
- `season` (required) - Season year

**Example:** `/api/picks/live-status?userId=1&week=1&season=2025`

**Response (200 OK):**
```json
{
  "picks": [
    {
      "gameId": "1",
      "teamId": "1",
      "autoGenerated": false,
      "isCorrect": null
    },
    ...
  ]
}
```

## Error Response Format

All error responses follow this format:

```json
{
  "error": "Error message description"
}
```

Common HTTP status codes:
- `200` - Success
- `400` - Bad Request (validation error)
- `401` - Unauthorized (invalid/missing token)
- `404` - Not Found
- `409` - Conflict (e.g., duplicate email)
- `500` - Internal Server Error

## Notes

- All timestamps are in ISO 8601 format (UTC)
- Game locks are enforced server-side based on `gameDate`
- Auto-generated picks are created for users who miss the deadline
- Leaderboard tie-breaking: Points → Percentage → Alphabetical
