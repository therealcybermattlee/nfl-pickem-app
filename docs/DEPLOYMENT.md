# Deployment Guide - NFL Pick'em App

Complete guide for deploying the NFL Pick'em application to Cloudflare Pages and Workers.

## Prerequisites

- Cloudflare account ([Sign up](https://dash.cloudflare.com/sign-up))
- Wrangler CLI installed (`npm install -g wrangler`)
- Node.js 18.x or later
- Git repository with the codebase

## Architecture Overview

The application consists of two parts:
1. **Frontend**: React SPA deployed to Cloudflare Pages
2. **Backend**: Cloudflare Workers API with D1 database

## Step 1: Install Wrangler CLI

```bash
npm install -g wrangler
```

Verify installation:
```bash
wrangler --version
```

## Step 2: Authenticate with Cloudflare

```bash
wrangler login
```

This will open a browser window for authentication.

Verify authentication:
```bash
wrangler whoami
```

## Step 3: Create D1 Database

1. **Create the database:**
```bash
wrangler d1 create nfl-pickem-db
```

2. **Copy the database ID** from the output. It will look like:
```
database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```

3. **Update `wrangler-workers.toml`:**
```toml
[[d1_databases]]
binding = "DB"
database_name = "nfl-pickem-db"
database_id = "YOUR_DATABASE_ID_HERE"
```

## Step 4: Initialize Database Schema

Execute the migration script to create tables:

```bash
wrangler d1 execute nfl-pickem-db --remote --file=migrations/0001_initial_schema.sql
```

Or execute schema manually:
```bash
wrangler d1 execute nfl-pickem-db --remote --command="
CREATE TABLE IF NOT EXISTS users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  email TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,
  name TEXT NOT NULL,
  role TEXT DEFAULT 'user',
  createdAt DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS teams (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  abbreviation TEXT NOT NULL,
  logo TEXT,
  conference TEXT,
  division TEXT
);

CREATE TABLE IF NOT EXISTS games (
  id TEXT PRIMARY KEY,
  week INTEGER NOT NULL,
  season INTEGER NOT NULL,
  homeTeamId TEXT NOT NULL,
  awayTeamId TEXT NOT NULL,
  gameDate DATETIME NOT NULL,
  homeSpread REAL,
  overUnder REAL,
  homeScore INTEGER,
  awayScore INTEGER,
  isCompleted BOOLEAN DEFAULT 0,
  winnerTeamId TEXT,
  oddsProvider TEXT,
  FOREIGN KEY (homeTeamId) REFERENCES teams(id),
  FOREIGN KEY (awayTeamId) REFERENCES teams(id)
);

CREATE TABLE IF NOT EXISTS picks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  gameId TEXT NOT NULL,
  userId INTEGER NOT NULL,
  teamId TEXT NOT NULL,
  autoGenerated BOOLEAN DEFAULT 0,
  createdAt DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (gameId) REFERENCES games(id),
  FOREIGN KEY (userId) REFERENCES users(id),
  FOREIGN KEY (teamId) REFERENCES teams(id),
  UNIQUE(gameId, userId)
);

CREATE INDEX idx_games_week_season ON games(week, season);
CREATE INDEX idx_picks_user ON picks(userId);
CREATE INDEX idx_picks_game ON picks(gameId);
"
```

## Step 5: Seed Initial Data

1. **Create test user:**
```bash
wrangler d1 execute nfl-pickem-db --remote --command="
INSERT INTO users (email, password, name, role)
VALUES ('test@example.com', '\$2a\$10\$hash...', 'Test User', 'user');
"
```

2. **Sync NFL teams and games:**
```bash
# Deploy the worker first (next step)
# Then call the sync endpoint
curl -X POST https://nfl-pickem-app-production.YOUR_SUBDOMAIN.workers.dev/api/odds/sync
```

## Step 6: Configure Secrets

Set the JWT secret for authentication:

```bash
wrangler secret put JWT_SECRET
# Enter your secret key when prompted (generate a strong random string)
```

Generate a strong secret:
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

## Step 7: Deploy Cloudflare Workers (API)

1. **Build the frontend** (required for Workers to have dist files):
```bash
npm run build
```

2. **Deploy to production:**
```bash
npm run workers:deploy-prod
```

Or manually:
```bash
wrangler deploy --config wrangler-workers.toml
```

3. **Verify deployment:**
```bash
curl https://nfl-pickem-app-production.YOUR_SUBDOMAIN.workers.dev/api/teams
```

## Step 8: Deploy Cloudflare Pages (Frontend)

### Option A: Automatic Deployment (Recommended)

1. **Connect GitHub repository:**
   - Go to [Cloudflare Dashboard](https://dash.cloudflare.com)
   - Navigate to Pages
   - Click "Create a project"
   - Connect to your Git repository
   - Configure build settings:
     - **Build command:** `npm run build`
     - **Build output directory:** `dist`
     - **Root directory:** `/`
     - **Node version:** 18.x

2. **Set environment variables:**
   - `VITE_API_BASE_URL` = `https://nfl-pickem-app-production.YOUR_SUBDOMAIN.workers.dev`

3. **Deploy:**
   - Click "Save and Deploy"
   - Pages will automatically build and deploy on every git push

### Option B: Manual Deployment

1. **Build the frontend:**
```bash
npm run build
```

2. **Deploy to Pages:**
```bash
npx wrangler pages deploy dist --project-name=nfl-pickem-app
```

3. **Configure custom domain** (optional):
   - Go to Pages settings
   - Add custom domain (e.g., pickem.cyberlees.dev)
   - Update DNS records as instructed

## Step 9: Configure Cron Triggers

Cron jobs automatically update game scores every 15 minutes.

1. **Verify cron configuration** in `wrangler-workers.toml`:
```toml
[triggers]
crons = ["*/15 * * * *"]  # Every 15 minutes
```

2. **Deploy with cron triggers:**
```bash
npm run workers:deploy-prod
```

3. **Verify cron is running:**
   - Check Cloudflare Dashboard → Workers → Your Worker → Metrics
   - Should see cron invocations every 15 minutes

## Step 10: Configure CORS (if needed)

If using a custom domain, ensure CORS headers are configured in `src/worker.ts`:

```typescript
const corsHeaders = {
  'Access-Control-Allow-Origin': 'https://pickem.cyberlees.dev',
  'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE, OPTIONS',
  'Access-Control-Allow-Headers': 'Content-Type, Authorization',
};
```

## Step 11: Verify Deployment

1. **Test authentication:**
```bash
curl -X POST https://YOUR_WORKER_URL/api/auth/signin \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"password123"}'
```

2. **Test frontend:**
   - Visit your Pages URL
   - Sign in with test credentials
   - Verify games load
   - Submit a test pick

3. **Test cron jobs:**
   - Wait 15 minutes
   - Check game scores update
   - Verify logs in Cloudflare Dashboard

## Troubleshooting

### Database Connection Issues

```bash
# Check database exists
wrangler d1 list

# Verify database ID in wrangler-workers.toml
wrangler d1 info nfl-pickem-db

# Test query
wrangler d1 execute nfl-pickem-db --remote --command="SELECT * FROM users LIMIT 1;"
```

### Worker Not Responding

```bash
# View logs
wrangler tail

# Check deployment status
wrangler deployments list

# Redeploy
wrangler deploy --config wrangler-workers.toml
```

### CORS Errors

- Verify `Access-Control-Allow-Origin` matches your Pages URL
- Check that OPTIONS requests are handled
- Ensure credentials are sent with requests

### Missing Teams/Games

```bash
# Sync data manually
curl -X POST https://YOUR_WORKER_URL/api/odds/sync

# Verify data
wrangler d1 execute nfl-pickem-db --remote --command="SELECT COUNT(*) FROM games;"
```

## Monitoring

### Cloudflare Dashboard

1. **Workers Analytics:**
   - Navigate to Workers → Your Worker → Metrics
   - Monitor requests, errors, CPU time

2. **Pages Analytics:**
   - Navigate to Pages → Your Project → Analytics
   - Monitor page views, bandwidth

3. **D1 Analytics:**
   - Navigate to D1 → Your Database
   - Monitor queries, storage

### Logging

View real-time logs:
```bash
wrangler tail --format=pretty
```

Filter by status:
```bash
wrangler tail --status=error
```

## Updating the Application

### Update Workers:

npm run workers:deploy-prod

### Update Frontend (Automatic):
```bash
git push  # Pages auto-deploys on push
```

### Update Frontend (Manual):
```bash
npm run build
npx wrangler pages deploy dist
```

### Database Migrations:
```bash
wrangler d1 execute nfl-pickem-db --remote --file=migrations/0002_new_migration.sql
```

## Rollback

### Rollback Workers:
```bash
wrangler rollback
```

### Rollback Pages:
- Go to Cloudflare Dashboard → Pages → Your Project → Deployments
- Click "..." on previous deployment
- Select "Rollback to this deployment"
